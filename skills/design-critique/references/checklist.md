# Critique Checklist

Work through each area. Only report what materially affects the design's goal.

## Hierarchy
- Is there one clear focal point? Does it match the most important message or action?
- Do size, weight, color, and position agree about what matters most?
- Can the main message be understood in a 3-second glance?

## Layout and spacing
- Is there an underlying grid, and do elements align to it?
- Is spacing consistent (ideally on a scale such as 4/8/16/24/32/48)?
- Are related items grouped closer together than unrelated ones (proximity)?
- Is there enough whitespace, or does the design feel crowded?

## Typography
- No more than two typefaces; a limited set of sizes on a clear scale.
- Body text readable for the medium (web ≥16px; print ≥10pt; slides ≥24pt).
- Line length roughly 45–75 characters; line height ~1.4–1.6 for body text.
- Headings clearly distinct from body; no all-caps paragraphs.

## Color and contrast
- Limited palette with a clear role for each color (primary, accent, neutral, status).
- Text contrast meets WCAG AA: 4.5:1 for body, 3:1 for large text and UI components.
- Color is not the only carrier of meaning (pair with icon, label, or pattern).

## Consistency
- Repeated components (buttons, cards, icons) share the same style.
- Corner radii, shadows, and stroke weights are consistent.
- Imagery shares a style (photo vs illustration, treatment, crop).

## Accessibility and usability
- Interactive targets at least 44×44px on touch devices.
- Clear affordances: buttons look clickable, links are distinguishable.
- Reading order makes sense if the layout collapses (mobile, screen readers).
