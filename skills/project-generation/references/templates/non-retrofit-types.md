# Non-Retrofit project types

Source: Project Timeline Template.md (completed jobs owned by Hyla Zouzias, Aug 2025 to Apr 2026). Sample sizes are small, so nothing here is a validated rule set. For every type below: build from the Retrofit base (`retrofit-rules.md`), add or remove blocks, and use the figures here as a sanity check on total length. Say in the assumptions that the type rests on a thin sample.

If the type or a parameter that changes the structure is not covered (EV charger, commercial maintenance), ask Zach once for the task chain or a comparable live project, then inspect it with the connector.

## 1. Non-PV Install (battery add-on)

5 projects, typical length 85 days (range 64 to 115). Structure (assumption, not validated by the data): the Retrofit base with Module Install removed and the battery block on; confirm against a live battery-only project. Typical close days: Design Process 11, Customer Documentation 15, NCUC 16, Technical Site Survey 28, Permit Application 33, HOA Application 40 (only 2 projects had one; HOA approval never recorded as required), Electrical Install 63, Interconnection Application 76, Electrical Inspection 85, Energize System 85. Handoff, Panel Mapping, Grid Export and monitoring review about day 89 to 90 (1 project).

## 2. Addition

Key dates: Welcome Email 6; Customer Documentation 11; Design 12; Site Survey 13; Permit closed 26; Module and Electrical Install 63 (37-day wait after permit, the longest stretch); As Built Review 73; Commission and Panel Mapping 74; Electrical Inspection and Energize 81; Building Inspection and COC 87; Interconnection, Handoff, Grid Export, monitoring review 87.

## 4. New Construction

1 project (P-2238, New Hanover AHJ, Duke Energy Progress NEM), 82 days. The workflow differs from Retrofit: it adds Rough-In and Trim-Out phases coordinated with the builder, a Builder Introduction task, and Electrical Rough-in before Module Install (trim-out). Key dates: Design 1; Builder Introduction, HOA, Welcome Email, Electrical Rough-in 16; Module Install (trim-out) 40; Access Handoff 54; Rough-in Inspection, Electrical Install, Inspections, Permit, NCUC, Energize 61 (batch-closed, so real dates were likely earlier); Interconnection Application and Receive PTO 79; Panel Mapping 82. P-2867 (Smedley, Surf City, JOEMC) is a live new-construction job and the closest comparison; the builder contact goes in the project description, not the task structure.

Ask for: builder involvement, expected rough-in window, and whether drywall timing gates install.

## 5. Service

1 project (P-2408, uninstall, clean, reinstall), 53 days, no AHJ or utility recorded. Key dates: Design 7; Permit 12; Uninstall, Installation and Cleaning, Inspection 39; Interconnections 53. Ask whether the job is a repair, a roof-related removal and reinstall, or a monitoring or inverter swap, since the task chains differ.
